# Contributing

Pull requests, compatibility reports, bug fixes, tests, and documentation translations are welcome.

1. Open an issue describing the camera model, firmware and problem.
2. Fork the repository and create a feature branch.
3. Run `python3 -m unittest discover -s tests -v`.
4. Open a pull request with changes and verification details.

**Never post unredacted network captures, camera credentials, device identifiers, tokens, or personal data.** Prefer synthetic fixtures. The live Wi-Fi integration remains experimental; do not claim a model has been verified without a reproducible test.
